# Windows 瀏覽器版 v0.1.5-desktop

下載 `BilliardManager-windows-x64.zip`，完整解壓後執行 `BilliardManager.exe`。本版在本機瀏覽器操作，不需要安裝 Python 或 WebView2。

## 本次修正

- 縮減球檯數時，已過期、已完成或已取消的預約不再阻擋設定。
- 未填結束時間的預約仍以開始後一小時計算。
- 縮桌後保留歷史預約與原桌號，不會刪除或錯誤換桌。
- 新增下載版驗收報告及正式發布檢查清單。

## 注意事項

- 目前尚未接上實體燈控，免費練習只記錄球檯使用狀態。
- 資料預設保存在 `%LOCALAPPDATA%\BilliardManager`，更新前請先建立備份。
- 本程式只在本機 `127.0.0.1` 執行，不需要連線到網際網路，也不應公開連接埠。
- ZIP 內附完整操作、備份及回退說明；SHA-256 請以本 Release 的 `SHA256SUMS.txt` 核對。
