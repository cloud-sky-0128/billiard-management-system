撞球館管理系統 Windows 免安裝版
================================

使用方式
--------

1. 請先完整解壓縮 ZIP，不要直接在壓縮檔內執行。
2. 進入 BilliardManager 資料夾。
3. 雙擊 BilliardManager.exe。
4. 等待瀏覽器自動開啟 http://127.0.0.1:8765。
5. 使用期間請保留黑色程式視窗；關閉該視窗就會停止系統。

Windows 第一次執行可能顯示 SmartScreen 警告。請先確認檔案是從本專案的
GitHub Releases 下載，再選擇「其他資訊」及「仍要執行」。第一版尚未購買
程式碼簽章憑證，因此 Windows 可能無法辨識發行者。

資料保存位置
------------

資料預設不會放在程式資料夾，而是保存在：

%LOCALAPPDATA%\BilliardManager\billiard.db

備份保存在：

%LOCALAPPDATA%\BilliardManager\backups

錯誤日誌保存在：

%LOCALAPPDATA%\BilliardManager\logs\app.log

系統啟動時建立當天的備份及日內快照；程式持續執行期間每 15 分鐘
建立新快照，換日後另建每日備份。在「整體設定 > 資料保護」可手動備份、檢查
磁碟空間警告及執行不覆蓋正式資料的還原演練。
系統保留最近 16 份日內快照、30 天每日備份及最近 12 個月每月備份，過期的自動備份
會清除。手動、資料遷移前及清除資料前備份不會自動刪除，仍請定期
檢查磁碟空間。
每份備份都包含當下完整的 SQLite 資料庫，並非只保存新增資料。每日備份只保存
當日第一份狀態；之後的變動由 15 分鐘快照保存。設定頁若發現快照不存在、
損壞或超過 30 分鐘未更新，會顯示警告。

建議額外使用另一顆磁碟或外接硬碟：從 PowerShell 設定
`$env:BILLIARD_BACKUP_DIR='E:\BilliardBackups'`，再從同一視窗執行
`BilliardManager.exe`。只把備份放在 C 槽，無法防止整顆硬碟故障。

若首次建立資料庫時 Windows 不允許寫入上述位置，程式會改存到解壓縮資料夾內的
`BilliardManager\data`。之後會沿用已存在的資料庫；若兩處都有資料庫，程式
會停止啟動，避免無聲切換。請先核對資料，再從 PowerShell 設定
`$env:BILLIARD_DATABASE='完整的正式資料庫路徑'`，並由同一視窗啟動程式。
若既有資料庫所在目錄暫時不能寫入，程式也會停止，不會開一份新資料庫。
使用預設位置時可直接替換程式；若程式內出現 `data` 資料夾，更新前必須先保留該資料夾。

若要完整移除所有資料，請在程式關閉後刪除 `%LOCALAPPDATA%\BilliardManager`
及解壓縮目錄內的 `BilliardManager\data`（若存在）。

常見問題
--------

- 瀏覽器沒有自動開啟：手動輸入 http://127.0.0.1:8765。
- 網址無法連線：確認 `BilliardManager.exe` 的黑色視窗仍在執行，並確認網址是 `http://127.0.0.1:8765`，不是開發版使用的 `5000`。
- 啟動失敗：新版會直接顯示錯誤對話框；請記下完整訊息再回報。
- 啟動或備份失敗：查看上述 `logs\app.log`，並檢查磁碟是否已滿或外接硬碟已拔除。
- 顯示連接埠被使用：先關閉另一個 BilliardManager，再重新執行。
- 防毒軟體掃描較久：免安裝程式第一次執行時可能需要等待。

安全提醒
--------

更新程式前，先在設定頁手動備份並執行還原演練，再關閉程式。
若要回退資料，必須在程式關閉後先另存目前的 `billiard.db`，
再把備份複製回原位置；這會失去備份之後的新紀錄。不要在程式
執行中覆蓋資料庫。若更新後資料庫 schema 已改變，舊版 EXE
可能無法直接開啟新版資料；請使用升級前的資料庫備份。

這是單機測試版，只監聽 127.0.0.1，其他電腦不能直接連入。請勿自行設定
Port Forwarding 或將它公開到網際網路。
